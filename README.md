# UPI Transactions Dashboard

### 📊 Power BI | 📗 Excel | 🔖 Bookmarks & Slicers

An interactive **UPI Transactions Dashboard** built in Power BI to explore transaction activity across different months, users, merchants, payment methods, locations, and transaction attributes.

The main focus of this project was building a **clean and interactive Power BI report using synchronized slicers, bookmarks, and multiple visual views**.

---

## 📌 Dashboard at a Glance

The dashboard allows users to explore UPI transaction data using filters such as:

- 🏦 Bank Name Sent
- 🏦 Bank Name Received
- 📍 City
- 📱 Device Type
- 👤 Gender
- 🎂 Age Group
- 🏪 Merchant Name
- 💳 Payment Method
- 🎯 Purpose
- 🔄 Transaction Type

---

## 📈 Transaction Analysis

The dashboard visualizes **monthly transaction performance for 2024**.

The same transaction data can be viewed through different visual formats, including:

- 📈 Line Chart — Amount
- 📊 Column Chart — Amount
- 📈 Line Chart — Balance
- 📊 Column Chart — Balance

This provides multiple perspectives for understanding transaction and balance trends over time.

---

## 🔖 Power BI Bookmarks

A major part of the project was using **Bookmarks** to switch between different chart views without creating separate dashboards.

Users can switch between:

```text
Line Chart Amount
        ↕
Column Chart Amount

Line Chart Balance
        ↕
Column Chart Balance
```
## 🎛️ Slicer Synchronization

Multiple slicers were added and synchronized across the report to maintain consistent filtering.

The project demonstrates the use of:

Interactive dashboard navigation
